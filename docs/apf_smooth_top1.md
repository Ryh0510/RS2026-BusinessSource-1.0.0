# Top-1 APF 之字形轨迹平滑修复

原有APF积分会留下局部折角，而旧后处理以曲折APF自身的关节弧长为参数、仅使用128/64/32/16点窗口，又受原APF关节盒限制，导致小尺度回折难以消除。离散Top-1本身的分支跳变也会导致关节插值的TCP大幅绕行。

## 最终实现

1. CDF接收Top-K来源的原始Cartesian目标。允许等价端点构型时，直接连续求解原始完整TCP位姿，逐点实际FK及限位校验；仅对真实continuous轴提升圈数。实际起终位姿最后再次验证，不使用任意取反或把所有角wrap到±pi。
2. APF连通后按原始有序TCP折线的弧长参数进行多尺度精化，窗口128/64/32/16/8/4/2点，正弦平方包络和回溯步长处理接缝。默认强度6对应两组尺度。TCP走廊替代噪声APF种子的额外关节盒，真实关节限位保留，QP的seed corridor仍有效。
3. 实际FK/Jacobian将越界的平滑提案投影到100mm上限的99%，随后仍检查完整关节运动；投影本身不是成功判据。
4. 接受窗口必须降低包含接缝的二阶弯曲代价、不得增加关节长度、不得制造比当前窗口更尖锐且超过45度的新角、不得降低已达到的最小节点间距，同时通过真实碰撞与有序TCP走廊验证。45度是禁止恶化的门槛，不是最终所有角小于45度的承诺。
5. APF阶段栏现在显示精化后、QP前的路径。保持一轮主QP，之后再次受约束平滑。最终全路径发布检查从最多0.001rad加强到最多0.00025rad；检测失败拒绝发布，不能只依赖节点或较粗检查。

GUI新增“保持起终TCP位姿，允许等价逆解构型”，本次按已获用户授权默认勾选；取消后保留原选关节构型。只有携带原始Cartesian目标的Top-K来源启用，单独导入关节TXT不会凭空恢复原目标。“碰撞约束平滑强度”0关闭，1–3/4–6/7–12分别一/二/三组尺度。
