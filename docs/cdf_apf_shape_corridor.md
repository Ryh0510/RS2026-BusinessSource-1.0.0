# APF 保持之字形路径与可配置末端走廊（默认 100 mm）

## 实现行为

用户先指定 50 mm，随后明确改为 100 mm。CDF 页新增“APF 末端最大偏移”，以 mm 输入，最新默认 100。它与 Seed corridor（关节弧度）分开：后者不能代替实际 TCP 位置限制。默认仍一轮 QP。

ProjectMotionPlanning 使用当前已标定世界 TCP 的独立 FK 快照。参考位置来自原始关节控制点的实际 TCP，原始控制点之间采用 Cartesian 折线；加密节点记录原始段编号和比例。因此不把关节插值自身产生的大弧作为目标形状。此规则用于已给定关节初始解的避障阶段，不改变 Basic Planning 直接对输入笛卡尔位姿求全逆解的流程。

对原始段 a，原始控制点 TCP 为 p_a、p_(a+1)，加密节点比例为 s，则其有序位置参考为 (1-s)p_a+s p_(a+1)。对每条输出关节线段，以同一比例插值对应 TCP 参考，实际 FK 位置距离默认必须不超过 0.10 m。验证按最大单轴关节变化 0.001 rad 采样，包含两个端点，任何失败均拒绝。这里是高密度数值验收，不声称对采样间无限多个点给出数学认证。

APF 的变化：

- 按原路径顺序逐站推进，保留首尾锚点与加密节点对应；不再直接连接整个避障区间末端。
- 障碍势场前瞻约 120 mm（最多 7 个前方参考站点），在折返/转角处停止；将当前关节偏移传递到前方站点，批量查询实际模型距离。当前位置距障碍小于 20 mm 时优先采用当前位置梯度，避免前方风险覆盖眼前的碰撞。局部 TCP 吸引前瞻仍为约 30 mm。
- 障碍物距离梯度排斥、正反向确定性切向逃逸、最大 0.02 rad 回溯步长、同向力滤波、停滞/迭代预算限制。
- 到达参考站点的前进平面时截断积分步，避免一次更新跳过多个加密站点；已有偏移逐站衰减，避免立即拉回参考而形成锯齿。
- 不做跨越扫描线的整段捷径或全局重采样。新增局部回退：将安全积分曲线分配到前面 4/12/32/64/128 个站点，每一候选逐段重新验证原参考对应和真实碰撞，原点数及首尾锚点不变。验收失败的重分配不采用。
- 固定安全锚点按至少 12/40/120 个采样点及 60/120/240 mm 原始 TCP 折线长度扩展；锚点碰撞时向外寻找，避免缩回接触附近。最后一次尝试使用实际有限关节范围，TCP 100 mm 硬上限不变。
- 用实际 FK 的阻尼 Jacobian 校正关节插值的 TCP 弯弧，作为势场吸引参考；其他尝试加入平滑的早期关节偏移及腕部过渡。关节目标吸引增加位置零空间分量，避免只跟踪 TCP 而无法恢复终点腕部构型。
- 末端锚点单独允许最多 500 次积分，仍受每场总预算限制；其停滞指标以关节目标差为主。更新越出 TCP 走廊时先尝试投影回走廊再检查真实扫掠运动。组合力受阻时尝试沿距离梯度恢复间距，候选必须确实增加距离且运动无碰撞。

碰撞段和 TCP 越界段统一交给 APF 修复，但诊断中分别统计。节点必须满足实际碰撞与 TCP 参考限制才可以成为固定安全锚点。APF 后完整路径必须同时通过两项验收，才能开始 QP。

窗口平滑获得绝对起始下标，按照原始参考检查，不能用全局最近位置匹配而跳到另一条扫描线。QP 和回溯候选、局部修复输出、最终输出均受同一走廊约束。最终碰撞检查保留现有新鲜 0.001 rad 复验。

## 界面与诊断

CDF 的 TCP 投影/坐标分页新增绿色“原始控制点折线”，可与输入、APF、最终 TCP 比较。位置最大偏差指标改为相对该折线的对应节点偏差；姿态指标仍相对输入关节插值，并明确不是锁定末端姿态。所设偏移上限仅约束位置。

未通过 APF 的阶段标为“未通过验收，仅供诊断”。保留阶段数据用于查看、导出和仿真调试，优化结果不会写入项目计划，QP 不会在失败路径上继续运行。失败消息包含加密节点区间、所设偏移限制和换用其他 Top-K 起点构型的建议。APF 失败不证明走廊内没有可行解。

公开领域选项新增 apfMaxTcpDeviation=0.10。启用时若无实际 TCP FK，明确拒绝；旧 headless 工具缺少标定 TCP，显式设置为 0 并记录走廊关闭，不能把该模式当成受限 TCP 验收。无新增第三方依赖、SDK 修改或项目持久化字段。
