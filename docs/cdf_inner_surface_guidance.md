# CDF 内表面喷涂姿态引导

## 使用

通过外部 `Freeform_APF_QP/run_ryh.cmd` 打开当前 ABB4600+A.STL 场景，在 Basic Planning 导入原 `ryh.txt`，全逆解并选全局 Top-1，点击“使用该结果作为优化初始解”。CDF 页面自动识别工件源目录的 `spray_guidance.json`，默认勾选“内表面喷涂姿态引导（允许调姿与喷距）”。点击原 APF/CDF/QP 优化按钮即可执行完整共享流程。

勾选模式允许改变中间姿态与喷涂距离，但保持原起终完整 TCP 位姿。原 TCP 最大偏移仍由页面输入约束；本次为100mm。以配置的0.1mm为软余量，无碰撞和内表面喷射方向是硬要求；不是10mm余量承诺。取消勾选后恢复普通APF/CDF流程及其页面参数。

此标定配置针对当前机器人、完整喷枪、A.STL和固定位置。模型源、网格、基座、工件位置、TCP或完整检测器过滤变化会拒绝使用旧配置；其他工件不能直接套用。标定数据使用米、弧度；导入原矩阵轨迹的位置仍为毫米。

## 共用流程

1. 从原导入的末端完整位姿与已选Top-1开始，逐点用实际FK核验种子，保留连续关节turn；不以种子FK代替原末端输入。原分层图/Top-M不检测碰撞的规则保持。
2. 先生成保持原TCP位置的径向/混合调姿候选，困难处再增加10、20、40、60mm偏移候选；旧4条轴向基线、9种径向/短喷距候选保留作补充。首尾各4点以smoothstep过渡，首末完整原位姿保持。
3. 使用实际TCP数值IK、合法turn、限位、完整碰撞距离和内表面喷射锥筛选；二阶束搜索综合关节位移、斜率变化、位置偏差和软间距代价，选择连续引导。此步骤发生于原Top-1之后，不修改原Top-K图边。
4. 对安全引导调用原APF修复连接，从5mm局部引导走廊开始，必要时依次尝试10、20、30mm，采用最窄成功结果，再进行碰撞约束平滑及一轮CDF/QP。所有更新仍检查喷射方向，最终独立核对原轨迹走廊。
5. 对可执行节点按几何、姿态和关节插值误差安全减点，保留全部原站点的有序参数对应；使用校准URDF运动上界对完整关节直线插值进行自适应间距验收。需要时用局部正弦平方小扰动修复，并重验全部连接。
6. 每段按关节速度、保守离散加速度和400mm/s TCP速度上限局部重定时，不用局部尖峰统一拖慢整个轨迹。
7. 独立以最大0.0001rad步长核验碰撞、限位、喷射朝向、原位置走廊、起终位姿、离散速度/加速度。失败不发布最终轨迹。

CDF阶段栏增加完整验收后的第四阶段；每个阶段的TCP偏移均以原末端轨迹为参考。优化日志旁有 `.guidance.json` 与 `.motion.json` 记录选择与运动证书。

## 脚本

- `run_ryh.cmd`：校验并复用已完整验证的结果，打开原MainWindow。
- `run_ryh.cmd --force`：从已求得的原Top-1重算共享姿态引导、APF/QP和验收。
- `run_ryh.cmd --force --rebuild-guidance`：先重算原全逆解/Top-30，再执行共享优化。

## 2026-10-16 往返扫掠段纵向覆盖保留

旧流程虽然保留全部原始参数站点和整条轨迹起终位姿，但表面投影/短喷距候选以及100mm位置走廊允许每次往返的中间折返点沿工件长轴回缩。对原ryh的实际关节插值FK复核，100个远端折返点最大回缩63.230mm，99个近端折返点最大回缩22.490mm；因此不能仅凭起终点不变或站点数不变判断覆盖完整。

现在共享服务将每个引导候选的位置沿标定工件长轴投回原始站点的轴向坐标，保留横向避让和姿态自由度。profile可用`axial_tracking_tolerance_m`设置最终有序纵向误差，缺省为0.002m。此误差以原始源参数对应的参考位置计算，不以最近几何点代替有序对应，也不将表面投影后的引导当成原轨迹。

保留原位置的候选仍优先遍历；横向偏移/短喷距候选集中到调姿不足站点及邻域。若某站点仍没有安全候选，则在局部扩大俯仰及绕喷射方向的转角候选，让长喷枪通过姿态改变避开边缘，而不是缩短纵向覆盖。该搜索为有限局部候选搜索，不是任意输入可行性的证明。原Top-M图及其不做碰撞剪边的规则保持。

同一轴向覆盖判据用于APF/CDF更新、连接减点、运动界补修和最终密验收。最终还显式检查全部原始站点的实际关节插值FK，以及完整源参数起止范围。无法同时满足覆盖、碰撞及内表面喷射方向时，拒绝发布新结果，不返回缩短后的轨迹作为成功结果。

外部原生入口另存`coverage_validation.json`，独立报告密采样及所有原站点的最大轴向偏差；脚本将该证书及其哈希纳入缓存验收，旧的无覆盖证书结果不能冒充新结果。


本次还移除了喷涂后处理引导中相邻原始站点单关节变化超过0.65rad的固定剪枝，改为对超过部分施加二次代价。实际困难段的安全调姿候选需要超过此差值；任意固定阈值不能代替连续可行性判断。原始Top-M分层图规则不变。输出仍须通过后续密化、APF、整段碰撞/工艺验收及重定时；大角度候选不会绕过验收成为成功结果。


为使APF能主动满足较窄覆盖带，增加可选`tcpStateProjection`回调。共享喷涂服务按实际FK计算轴向误差e与轴向位置Jacobian a，使用阻尼最小范数修正dq=-e*a^T/(a*a^T+lambda)，配合步长/限位/回退，将提议状态投回半宽覆盖带，为关节插值留出余量。此投影不改变TCP/FK模型，也不宣称提议无碰撞；每次更新、平滑窗口和最终运动仍重新验证碰撞、喷射方向和完整有序参考。普通无回调规划保持原行为。


进一步的固定位置探查表明，原先的俯仰/绕喷射轴转动会把长枪身横扫到腔壁。新增绕工件长轴的喷射方向方位角候选（±15至±90度）：保持TCP位置与长枪插入轴，改变喷射方向，让偏置喷嘴/枪体避开狭窄端部。优先在原位置搜索这些大姿态变化，再按需要尝试横向位移；仍逐一验证实际FK、完整机器人/喷枪碰撞、内表面正侧与喷射射线及61度入射限制。允许改变原喷射落点，不能据此宣称原喷涂厚度分布不变。

安全候选复用nearestDistance返回的距离；该查询已执行同一场景的限位/状态更新和全部所选检测器碰撞检查，避免在同一状态重复运行validateState及第二次nearestDistance。最终整段认证与独立密验收不减少。


APF积分提议的工艺投影采用提议TCP在当前有序参考段上的投影进度，避免把每次小步直接吸到下一站轴向坐标；只有该段最终发布节点才需匹配下一站。回填历史站点时重新施加工艺投影，再完整验证每条连接。新增薄障碍/轴向覆盖夹具验证分步绕行、最终有序覆盖和所有输出弦无碰撞；无工艺投影回调时保留普通路径逻辑。


在后处理调姿图中增加惰性连续连接偏好：只检验当前选中序列的相邻姿态，按25mm平移/0.1rad转角采样SE(3)插值，用实际模型连续局部IK检验中间构型、喷射方向、碰撞及末端分支一致性。缓存检验结果，对不能直接调姿连接的候选边加代价，再选择整条引导，最多12轮；未消除的局部连接仍交APF处理，不把节点安全当作路径安全。此阶段位于原全逆解/Top-M之后；原全二部Top-M图及无碰撞筛边规则不变。

原位置偏移代价权重默认从0.08提高到8（profile可选guidance_position_weight），优先姿态调整。不同探查曲线交接后按实际关节范围继续合法turn，避免等价姿态产生不必要整圈；依旧通过实际FK复核及全路径碰撞验收。外部私有诊断入口可通过共享服务的同步guideObserver保存guide_checkpoint，该目录只有安全节点引导，不是通过APF/QP或整段认证的最终结果。
