# APF/CDF 阶段检查与平滑修复

## 使用

1. 在 Basic Planning 中将全局 Top-M 选中的序列作为 CDF 初始解，或导入关节 TXT。
2. 在 CDF 页执行 APF + CDF/QP。默认仍是一轮 QP，曲率平滑权重为 2，碰撞约束平滑为 6 轮；原初始关节栏始终保留。
3. 在“阶段结果检查”中选择输入（加密参考）、APF 避障结果（QP 前）、CDF/QP 最终结果。各阶段可以应用单点、动态播放（自动开启末端轨迹线）、导出 TXT。
4. 点击“查看阶段对比与质量报告”：查看质量/实际使用限位表、关节形状、速度、离散加速度、TCP 投影/坐标/速度和验收日志。图上可以选择关节或投影轴，开关各阶段曲线。
5. 可导出质量 CSV。阶段 TXT 保留现有时间秒/逆解符号关节角度格式，可以再次导入。

预览时长只控制观察速度。“按记录时间 1× 播放”使用轨迹时间戳，渲染过载时显示仍会放慢。报告中的速度始终由记录时间计算。

## 根因与修复

旧 QP 的一阶差分主要缩短路径，无法充分抑制折角；数值回退可能把平滑权重降为零；后处理又会因单个局部安全余量降低而全部撤销。现在采用非均匀参考弧长参数下的二阶目标：

`J_bend = sum_i 2/(ds_left+ds_right) * ||(q[i+1]-q[i])/ds_right - (q[i]-q[i-1])/ds_left||²`。

种子跟踪项按节点积分权重计算，稀密节点不再具有不一致的影响。回退保留曲率权重；正则项追踪当前路径，避免向零关节角偏置。多尺度后处理只提交弯曲代价下降、走廊内、节点余量与高密度运动检查合格的局部窗口，首尾不变。

比较三个阶段时始终使用同一原输入加密参考参数，不用重新定时造成的速度降低冒充几何平滑改善。QP 采用上三角五带唯一条目，避免重复 Hessian 项。

## 指标解释

- 关节长度和二阶弯曲代价越小通常越好；最大折角可揭示残留局部突变。
- Phi 是节点最小有符号距离减去 safety margin。无碰撞与达到安全裕量是不同状态；Phi 小于 target clearance 时会明确报告未收敛。
- 最终运动检查角度步长不超过 0.001 rad，不以节点检查代替轨迹段检查。
- 默认重新定时修复非递增时间，使用模型动态限位；缺失时使用可配置的 60 deg/s、120 deg/s²，报告给出缺省轴数。这不是厂家认证的动态限位。
- 时间缩放只改变时间/qd/qdd，不改变关节几何或 turn。节点加速度是有限差分；分段线性折点的连续物理加速度没有得到认证，不能直接视为实机执行认证轨迹。
- TCP 偏移以实际基座/工具 FK 对同一输入参考节点计算。避障会改变末端位姿，不保证严格保持原控制点。原输入有碰撞时，精确保留该构型与无碰撞本身不兼容。
- Top-M 的全局最优只针对离散图中的关节变化代价。APF/CDF 是局部避障与平滑，报告没有将其称为非凸全局路径或时间最优。

## 数据所有权

ProjectMotionPlanning 拥有阶段快照、质量计算、QP/碰撞约束平滑与重新定时；Qt controller 只投影临时分析结果、执行既有 document/runtime 应用入口；对话框只展示快照。实际 TCP callback 在后台工作线程独占，不与可变碰撞查询场景共享。真实文档/几何变更使报告失效，单点应用、动态播放和工作台纯预览清理不会清除报告。没有新增依赖或项目持久化字段。

使用 ABB4600-burnner.sys.json、11111.txt 对应的 749 点全局 Top-1（实际 TCP FK 最大位置误差 0.000995748 mm、姿态误差 0.0000474286 度），比较 4592 个共同参考节点。默认一轮 QP、曲率权重 2、多尺度平滑 6 轮：

| 关节路径长度 rad | 181.10235 | 73.664924 |
| 同一参考参数弯曲代价 | 1.4394369 | 0.085887398 |
| 最大关节折角 deg | 176.92384 | 154.77863 |
| 不通过运动碰撞检查的段数 | 0 | 0 |
| 最小节点 Phi mm | -9.8283638 | -9.1901855 |
| TCP 路径长度 mm | 44389.393 | 30893.98 |
| 对输入最大 TCP 偏移 mm | 964.99825 | 993.51619 |

弯曲代价下降约 94%，但仍有局部折角，不能称为处处光滑。最终离散峰值速度 21.434217 deg/s、加速度 119.76036 deg/s^2，位置/速度/离散加速度越限均为 0。输入/APF 有两个非递增时间段，速度标为不可用而非伪造数值。最终保守时间缩放记录时长 5463.457 s，不能把这当成时间最优。

最终全部段通过独立重新导入、关节线性插值 0.001 rad 检查，起终点有效。Phi 仍为负，未达到设置的 10 mm 安全裕量，GUI 明确保存为未达到间距的部分结果；TCP 偏移接近 1 m/姿态约 152 度也需按实际工艺要求评估。局部平滑不能修复初始碰撞构型与严格保持末端目标之间的可行性矛盾。

首次完整 GUI 计算实测约 652 s，包含 APF、平滑、QP、碰撞验证和质量分析，并行构建/测试期间的墙钟时间，不是提速基准或耗时承诺。截图与三阶段 TXT/CSV 见外层 build/cdf-quality-results；最终回归证据以 build/cdf-quality-real-gui-final.log 为准。
