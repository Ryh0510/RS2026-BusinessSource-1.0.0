# FANUC LS 轨迹导入

Motion Planning 的普通导入与轨迹转换页均支持 `.ls` / `.LS`，选择机器人后导入即可；AZ500.LS 的 2480 条 L 指令转为 2480 个标准笛卡尔位姿点，沿用已有轨迹转换、逆解、多解和避障入口，不创建专用轨迹类型。

- 按 `/MN` 的指令顺序展开 P 引用，保留重复引用；不按 `/POS` 点号排序。
- XYZ 的 mm 转内部 m；WPR 的 deg 按 `Rz(R) * Ry(P) * Rx(W)` 转旋转矩阵。
- 按用户指定，与 TXT 一样直接解释源坐标；不额外猜测 UF2 或 UT1 的安装变换。UF/UT、CONFIG、原程序行号、P 编号、指令速度、FINE/CNT 记录在计划元数据。若需要与 ROBOGUIDE 世界场景对齐，可使用已有轨迹整体变换功能施加实际坐标系变换；工具 TCP 在工程中配置。
- LS 无时间戳，第一点设为 0，后续按相邻位置距离除以目标指令速度累计名义时间。零位移段采用导入默认步长 0.1 s。AZ500 名义时间约 422.739 s。这些时间不包含 FINE 停止/加减速、控制器动态限制或 CNT 混合，不代表控制器运行时间。
- 当前支持 GP1 的直线 `L P[n] ...mm/sec FINE/CNTn`。关节点、外部轴、多运动组、混合 UF/UT、J/C、循环/跳转/调用和未知执行指令明确报错，避免静默丢失运动语义。错误包含相关位置/指令信息；导入失败不修改工程。

用户已暂缓速度分析及绘图，本次没有增加此功能。
