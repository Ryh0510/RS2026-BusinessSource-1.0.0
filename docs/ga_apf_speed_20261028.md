# GA/APF 速度优化与验证（2026-10-28）

本轮修改 A 源码；不修改 RSW、原始桌面 `1.txt`、场景资源及工具安装参数。最终运行入口为外层 `build/Release/bin/RobotQtViewerrx64.exe`，可继续在原 VS2019 解决方案使用 Release/x64 启动。

## 实测结果

同一 FANUC 场景、100 mm、TCP yaw=180 度、喷射轴旋转开启，实际工具、实体检测器和虚拟挡板均启用。

| 本轮优化前 GA/APF/CDF 原生基线 | 1134.35 秒 | 4795 点 |
| 本轮默认 GA/APF 原生（最终空闲测量） | 24.12 秒 | 100 点 |

默认 UI 验证直接使用用户实际外层 build 程序及 VS 项目工作目录；驱动先断言复选框初始未勾选，再执行真实导入、规划、最近距离图和导出可用性检查。QP 全程耗时包含 GA/APF、实际接受的 CDF 及新的独立回放。关闭 QP 与开启 QP 的功能不同，不能把二者耗时差全部归因于计算加速。20 秒是目标，最终测到约 24 秒，不承诺每次固定 20 秒。

13 个原始控制点全部保留，12 个原始区间分段数量为 `[8,8,8,9,8,8,8,9,8,8,8,9]`，也就是每区间新增 7 或 8 点。100 为软目标；必要时由工艺细分补点并尽量均衡各区间，不因超过 100 点失败。额外回归覆盖 121 个原始控制点，确认不会丢弃控制点或因目标点数拒绝。

## 修改内容

- Qt 复选框和设置结构的 CDF/QP 默认值均改为关闭；保留手动开启。
- 在 ProjectMotionPlanning 设置约 100 个输出支持节点，按原始区间均匀分配。输出节点与细安全采样解耦；关闭 APF/CDF 盲目二次节点加密。必要节点仍由原始表面站点投影和工艺检查决定。
- 实际 6R 模型导出的 POE 链用于快速运动学数值计算；新增世界 TCP 几何雅可比。配置时与真实 runtime FK 及差分导数逐样本核对，接受候选继续检查真实 FK、物理界限和奇异性。
- GA 的 CPU 逆解回退并行执行，结果按原种子顺序合并；保留 GPU 无根时的 CPU 回退。对同一目标和同一初值的重复 IK 尝试精确复用，不减少初始池或进化轮次。
- 复用已有 CdfQueryBatch 私有线程池，每个工作线程独占碰撞/挂载/挡板 runtime。GA 最多 8 个、回放最多 4 个 worker，按硬件与资源自动退让；并行物理检测后仍验证工艺和奇异性，统计包含附加场景查询。
- 精确关节向量作为缓存键，复用同一不可变场景/请求中的距离与安全观察。APF 后仍创建新的场景进行独立回放；不跨阶段复用碰撞结论。
- 挡板网格构建包围盒树。CPU 保留逐三角形精确相交与封闭体包含检查，使用树先排除无关几何；光线包含检测仍保留原来的交点去重和紧包围盒规则。
- GPU 挡板评分只提交经包围盒树及三角形厚度范围筛选的候选；仍使用完整原网格的三角形数量归一化，避免改变遗传适应度。增大有界 kernel 批次，保持 FP64 及原计算规则。GPU 评分始终仅用于搜索，实际接受由独立物理检测决定。

GA 的 5000 个均匀面积候选、8 轮进化、24 个固定半径后代、独立追加变半径后代、无单点时间限制及取消机制均保留。原始表面球心不漂移，GA 最终喷距仍逐点锁定；本次 `1.txt` 的 13 个喷距均为 100 mm。
