# GA 表面球冠搜索与取消单点超时（2026-10-28）

## 实现规则

更新在 A 目录中，领域算法由 ProjectMotionPlanning 维护，工作台只收集参数。UI 的“GA 原始喷涂距离”以 mm 输入，默认 100 mm，内部换算为 m。

对原始 TCP 位置 P、原始局部 +Z 法向 n 和输入喷距 d，固定表面参考点 S=P+d*n。候选法向 n' 位于原法向 80° 半角球冠内，候选 TCP 为 P'=S-r*n'，始终朝向同一个 S。该表面参考点由原始数据和喷距构造，并未新增 STL 射线投影；输入距离不正确时，不能宣称 S 已落在真实网格表面。

每个原始控制点一次生成 5000 个不同的候选姿态。cos(theta) 均匀采样、方位角覆盖 360°，因此球冠上按面积均匀；先评估完整初始池，再执行原有 8 轮、每轮 24 个基本后代。找到安全姿态也不跳过完整初始池。没有额外打开自由轴向旋转。

| 进度（仍未找到安全姿态时） | 半径区间 | d=100 mm |
|---|---|---|
| 初始池、第 1、2 轮 | d | 100 mm |
| 第 3 轮 | 0.7d–1.3d | 70–130 mm |
| 第 4 轮 | 0.5d–1.5d | 50–150 mm |
| 第 5 轮及以后 | 0.2d–1.8d | 20–180 mm |

开放半径后先批量探索球壳，径向按壳体体积均匀分布；每批最多 256 个，随后继续交叉/变异。一旦找到经过实际 CPU 安全检查的父代，后续局部进化从这些安全父代繁殖，已开放半径区间冻结。GPU IK 和碰撞评价只辅助搜索，实际机器人、安装工具、工件和启用的虚拟挡板门禁保留。

工作台 GA 不再有单点 180 秒截止时间。默认请求及 JSON 缺省 `anchor_search_seconds=0` 表示不限单点墙钟时间；工作台也明确传入 0。每点 131072 次评估预算和 Cancel 仍保留。显式非工作台调用仍可传入正的时间预算。

GA、APF、CDF 及各次重新计时复用原始 S 和法向参考，并传递各点实际开放的半径范围，不以调整后的 TCP 重新构造球心。GA 仅保证控制点；APF 与独立回放检查采样段内状态，可选 CDF 失败时保留已接受 APF。采样通过不等于 SDK 保守整段运动证明。

## 代码范围

- `GaApfCdfPipeline`：喷距参数、固定原始球心、80° 约束、半径范围及重新计时映射、无限单点时间。
- `ExternalTrajectoryEvaluation` / `ExternalPlanningJson`：0 时间语义、完整初始池、安全父代、扩半径批量搜索与审计。
- `MotionPlanningEditorWidget` / `MotionPlanningModuleController`：喷距输入及领域参数传递。
- `GaApfCdfCheck` / `PlaybackWindowProfile`：100 mm 测试入口、表面/距离审计与 UI 参数报告。
- 领域和跨工作台回归：均匀性、3/4/5 轮范围、评估次数、安全父代、取消、安全失败、单位换算；CDF 跨工作台用例允许更长的测试进程超时（1800 秒），此项不限制应用的单点搜索。

本轮无新增第三方依赖，无已有 API 重命名；领域流程增加带默认值的喷距选项参数，已有四参数调用可继续编译。保留本轮前的场景、工厂数据及其他工作区修改。
