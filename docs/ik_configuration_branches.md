# ABB4600 多逆解构型标识

全逆解之后，每个候选包含固定的肩（S）、肘（E）、腕（W）几何分支。编号不会因该点缺少某个逆解而前移，也不会因数值搜索找到解的先后顺序而变化。

| 固定编号 | 肩 S | 肘 E | 腕 W |
| --- | --- | --- | --- |
| B1 | + | + | + |
| B2 | + | + | - |
| B3 | + | - | + |
| B4 | + | - | - |
| B5 | - | + | + |
| B6 | - | + | - |
| B7 | - | - | + |
| B8 | - | - | - |

`+/-` 是下面定义的几何分支，不是关节角正负，也不是 ABB RAPID 的 `confdata`。当前 CAD 模型并非严格理想球腕，不能直接用旧理想 DH 或某个关节的零度作为分支边界。

## 实际模型中的定义

分类器建立独立运行时模型快照，保留项目已有 IK 到机器人关节的符号映射，通过 SDK 的实际 FK 得到各关节轴在世界坐标系中的位置 `p1...p6` 和单位方向 `a1...a6`。工具变换不参与分类；世界基座的刚体旋转和平移不影响结果。

- 肩：取 `r = normalize(a2 × a1)`，使 `r·(p2-p1)>0`，即朝肩部偏置外侧。`S = sign(r·(p5-p1))`。正分支表示腕中心位于该朝向的前侧。
- 肘：`E = sign(a2·(normalize(p3-p2) × normalize(p5-p3)))`。这是上臂和前臂绕肩轴的有向弯曲两侧，包含实际连杆偏置。
- 腕：`W = sign((a4 × a6)·a5)`，用实际腕轴的方向区分腕部翻转两侧。
- `p5` 是当前六轴模型的腕中心参考点。分类不替代数值 IK，也不修改任何关节值或 FK 误差验收。
- 肩分支量在 `1e-5 m` 内、肘/腕归一化分支量在 `1e-5` 内时，该分量记为 `0` 并显示“边界”。这是几何分类边界，不是对模型精确运动学奇异性的证明。
- 无效输入或不支持的轴系显示“未分类”，不猜测为 B1～B8。分类器仅在 ABB4600 调用链中启用。

固定编号为 `1 + 4*[S<0] + 2*[E<0] + [W<0]`，三个分支均不为零时才使用。先按固定构型、再按 turn、最后按实际关节角排列候选。多圈候选保持独立，未归一化覆盖原始关节角。

## 界面和使用

- 重新执行“全逆解”，候选栏显示 `B编号 肩± / 肘± / 腕± | #候选序号`，`*` 仍表示当前播放解，原来的 turn、角度及误差列保留。
- “分层图筛选”的全局 Top-M 和按起点 Top-K 两页增加起点/终点构型，逐点明细增加固定构型列。图算法仍以实际候选及完整 turn 为节点，不合并相同构型的多圈解，也不增加碰撞检测或节点代价。
- “查看构型选择”默认勾选“按肩/肘/腕显示”。纵轴固定为 B1～B8，离散切换绘制为阶梯线，缺解不补点、不重编号。
- 悬停显示控制点、结果序号、构型、候选序号与 turn。取消该勾选可比较原始候选序号，避免同一几何分支的不同 turn 被重合曲线掩盖。
- 两页均保留任意多选、分行、控制点区间；摘要分别统计候选差异和构型分支差异。
- 单点应用、选解播放、两页“使用该结果作为优化初始解”仍使用原始候选关节值，不根据标签反推关节角。

## 验证入口

构建 `RobotQtViewer`、`RobotQtViewer-SprayMeasurementSmoke`、`IkGraphTests`，运行 `RobotQtViewerMultiIkSmoke` 和 `ProjectMotionPlanningLayeredIkGraph`。

`RobotQtViewer-SprayMeasurementSmokerx64.exe --multi-ik-project <项目.sys.json> <末端轨迹.txt> <报告.csv>` 可输出包含分支标签的全量 CSV 和完整轨迹对比图。回归覆盖实际 FK、八根区分、整圈不变性、基座不变性、腕分支边界，以及应用/播放/两页 CDF 传递。
