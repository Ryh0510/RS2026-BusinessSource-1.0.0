# Motion Planning 碰撞检测条件

Motion Planning 不再在打开工作台或工程时自动创建默认工件检测器。GA+APF+CDF、最近距离查询及带喷涂测量的播放，在运行前需要明确指定检测条件。

1. 在 Basic Planning 页点击“碰撞检测条件...”，或直接运行相关功能，在首次使用时设置。
2. 使用已有检测器：从当前工程的全局场景配置中选择一个或多个检测器（Ctrl 多选）。检测器须启用，且开启距离与最近点查询。所选检测器需共同覆盖当前机器人全部已启用的挂载工具；可同时选择本体检测器和工具检测器，也可选择已配置的全场景检测器。覆盖不足时对话框会提示补选或新建。原来的碰撞模型、检测对、过滤规则和距离阈值沿用原配置。
3. 创建检测器：勾选“创建新检测器”，选择场景中的工件（场景对象或另一机器人），勾选“启用全局碰撞查询”，确认后创建“当前机器人本体＋所有已启用挂载件”与该工件的检测器。目标为另一机器人时，也包含对方已启用的挂载件。隐藏显示的工具仍参与碰撞；禁用的挂载件不自动纳入。不会导入或恢复已删除的模型；高级检测对和过滤规则可继续在 Collision 工作台编辑。
4. 喷涂距离和角度还需指定“新检测器 / 喷涂测量工件”。它是喷嘴射线测量的表面目标，独立于多选检测器的碰撞范围。播放时记录测量值，播放结束后绘图或导出，图表与文本显示实际目标。

选择只属于当前工作台会话；创建的检测器属于工程，通过正常保存流程保存。取消对话框不创建检测器或启用全局查询。切换机器人、重开工程、禁用或删除检测器、增加或启用挂载工具后，运行前重新校验；机器人和工件自身的碰撞几何也须启用；没有有效检测对时显示具体错误。普通关节播放关闭喷涂测量且没有选择碰撞检测器时，可继续只播放运动。

此前创建的本体检测器不会被静默改写。若提示未覆盖工具，请在“碰撞检测条件...”中重新创建，或在 Collision 工作台给已有检测器配置工具选择集后再多选使用。挂载工具的碰撞状态与最近距离使用其随机器人运动的实际几何；喷涂距离和角度仍按工具 TCP 和所选表面目标测量。

本次调整仅通用化碰撞条件和测量目标，不改变 GA/APF/CDF、IK、TCP 或轨迹验收算法。机器人仍须满足对应算法原有的运动学及工具配置要求。旧单参数喷涂测量接口保留兼容，Motion Planning 使用新增的显式目标接口；无项目格式或第三方依赖变化。
