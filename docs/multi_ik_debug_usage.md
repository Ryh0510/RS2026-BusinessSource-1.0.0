# 多逆解调试使用说明

1. 启动本轮构建的 `build/Release/bin/RobotQtViewerrx64.exe`，打开机器人项目并选中机器人。build 位于源码根目录同级。
2. 在 Motion Planning → Basic Planning 导入末端控制点文件，如 `11111.txt`。IK target 根据文件的坐标语义选择 With tool TCP 或 Robot flange。
3. 点击“全逆解”。设置六轴搜索范围（度）和每点分散初值数，默认 [-180,180] 度、64 个初值。若需要多圈解，扩大相应轴范围。已有机械限位会自动限制范围；模型为 continuous 时，搜索范围不能视为真实机械限位。
4. 计算在后台运行，可查看完成点数或点击“取消全逆解”。改变源轨迹、机器人、工具等会使结果失效。
5. 在新增“多解关节轨迹”栏选择控制点，查看该点所有候选：六轴角度（度）、turn、TCP 位置误差（mm）及姿态误差（度）。turn 以 [-180,180) 度为基准表示整圈数。显示角度沿用项目已有 IK 符号，应用时自动做原有机器人符号映射。
6. 选择候选行后点击“单点应用所选解”，可立即查看机器人构型。高亮行与播放选择不同；点击“设为该点播放解”才改变该点的播放选择，星号 `*` 标记播放解。
7. “从所选解就近选取后续解”会固定当前选择，并逐点选择关节变化较小的后续候选。编号只在当前点内有效，相邻点相同编号不一定是相同构型分支。
8. 设置播放时长，点击“动态运行多解选定轨迹”。每个点只使用标记的一组解，支持停止；勾选“显示末端轨迹”可观察末端轨迹线。若任何点无解，则禁止完整播放。

该功能是实际模型的多初值数值搜索，不保证固定八组或数学意义上的穷尽。每点最多保存 512 组，达到上限会标记“已截断”。奇异位姿可能存在连续解族。

候选当前保存在调试会话中，不覆盖原始导入轨迹，切换项目/源轨迹后需要重新求解。动态运行是逐点构型调试，不表示连接段已完成避障或满足速度、加速度约束。多解调试播放不会自动执行 APF 或 CDF/QP。

真实文件验证：749 个点全部有解，共 5986 组候选。最大 TCP 位置误差约 0.001 mm、姿态误差约 0.000054 度。

## 分层图筛选与 CDF 初始解

1. 完成“全逆解”后，在 Basic Planning 的“分层图 Top-M 筛选结果”区域设置候选数 M（默认 30）及 J1..J6 权重（默认全为 1）。
2. 点击“分层图筛选”。计算仅使用相邻层间加权关节位移，不进行碰撞检查。可点击同一按钮取消。
3. 在排名表中选中一条结果，下方明细会显示该序列每点的时间、逆解编号、六轴角度和 turn。排名代价单位为 rad²；保存的角度包括整圈数，不按最短圆弧折回。
4. 点击“使用该结果作为优化初始解”，程序自动切换到 CDF 页，初始关节栏显示该条完整轨迹。无需导出/重新导入 TXT。
5. 使用 CDF 页现有的单点应用或 APF + CDF/QP 修复功能。可以回到 Basic Planning，选择另一条排名结果再次传入。

M 是本阶段保留的运动学候选数；这里尚未进行避障成功率或最终轨迹质量的 Top-K 排名。分层图结果不是无碰撞轨迹，后续由现有 APF/CDF 处理。未加入速度/加速度硬约束。

筛选针对已找到的多逆解集合精确求前 M 条不同的完整序列；若解的总组合数不足 M，显示实际数量。改变 M/权重、重新求逆解或使源逆解失效后需要重新筛选。分层图排名和 CDF 初始导入栏当前属于调试会话数据，不自动写入项目轨迹。

## 查看构型选择

1. 分层图筛选完成后，点击排名表下方的“查看构型选择”。弹窗默认勾选第 1 条和打开时选中的排名；两者相同则只勾选第 1 条。
2. 在左侧勾选任意数量的结果序列号，支持全选、清空。图例颜色和线型对应候选排名。
3. 横轴是原始控制点序号，纵轴是该点选择的逆解编号，均从 1 开始，与多解/分层图明细栏一致。折线包含每个控制点，不抽样、不做曲线平滑。
4. 默认在同一张图叠加；重合较多时勾选“分行对比”，每条轨迹单独一行，可滚动查看。上方可设置起止控制点，点击“全程”恢复完整范围。只看一个控制点也能显示对应编号。
5. 下方统计当前区间内至少两条所选序列选择不同的控制点数量。全不选时显示提示。
6. 更改筛选参数、重新计算或源逆解失效时，旧窗口自动关闭；新结果生成后可重新打开。

逆解编号只在同一个控制点内有意义，不是固定肩/肘/腕构型标签。相同控制点处的编号不同说明选用了不同候选，但相邻点编号的跳变不能直接解释为机器人关节跳变。该图显示当前分层图 Top-M 候选，并非 APF/CDF 优化后的重新排名。
