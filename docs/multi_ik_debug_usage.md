# 多逆解调试使用说明

1. 启动本轮构建的 `build/Release/bin/RobotQtViewer_MultiIKFixrx64.exe`，打开机器人项目并选中机器人。build 位于源码根目录同级。
2. 在 Motion Planning → Basic Planning 导入末端控制点文件，如 `11111.txt`。IK target 根据文件的坐标语义选择 With tool TCP 或 Robot flange。
3. 点击“全逆解”。设置六轴搜索范围（度）和每点分散初值数，默认 [-180,180] 度、64 个初值。若需要多圈解，扩大相应轴范围。已有机械限位会自动限制范围；模型为 continuous 时，搜索范围不能视为真实机械限位。
4. 计算在后台运行，可查看完成点数或点击“取消全逆解”。改变源轨迹、机器人、工具等会使结果失效。
5. 在新增“多解关节轨迹”栏选择控制点，查看该点所有候选：六轴角度（度）、turn、TCP 位置误差（mm）及姿态误差（度）。turn 以 [-180,180) 度为基准表示整圈数。显示角度沿用项目已有 IK 符号，应用时自动做原有机器人符号映射。
6. 选择候选行后点击“单点应用所选解”，可立即查看机器人构型。高亮行与播放选择不同；点击“设为该点播放解”才改变该点的播放选择，星号 `*` 标记播放解。
7. “从所选解就近选取后续解”会固定当前选择，并逐点选择关节变化较小的后续候选。编号只在当前点内有效，相邻点相同编号不一定是相同构型分支。
8. 设置播放时长，点击“动态运行多解选定轨迹”。每个点只使用标记的一组解，支持停止；勾选“显示末端轨迹”可观察末端轨迹线。若任何点无解，则禁止完整播放。

该功能是实际模型的多初值数值搜索，不保证固定八组或数学意义上的穷尽。每点最多保存 512 组，达到上限会标记“已截断”。奇异位姿可能存在连续解族。

候选当前保存在调试会话中，不覆盖原始导入轨迹，切换项目/源轨迹后需要重新求解。动态运行是逐点构型调试，不表示连接段已完成避障或满足速度、加速度约束。本轮不执行 Top-M、APF 或 CDF/QP。

真实文件验证：749 个点全部有解，共 5986 组候选。最大 TCP 位置误差约 0.001 mm、姿态误差约 0.000054 度。
