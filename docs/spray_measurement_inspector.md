# Motion planning 喷涂方向与测量查看

在 Basic Planning 页的“喷涂方向”中选择 `TCP Z+` 或 `TCP Z-`。方向相对于当前工具 TCP，范围锥体与喷涂距离、角度使用同一方向；默认 Z+。当前选项只属于分析会话，不修改工具安装、TCP 或轨迹姿态。

1. 设置碰撞检测条件与喷涂测量工件，勾选距离/角度计算；需要时勾选 Show spray range。
2. 播放所选轨迹以采集测量结果，结束或停止后点击“绘制喷涂距离和喷涂角度图”。
3. 点击任意一条曲线的横向位置选择采样点，两张图同步显示选中线；使用左右方向键或右侧“采样序号”可以逐点定位。
4. 右侧显示原轨迹点号（从 1 开始）、原始时间、世界坐标下的 TCP 位置、喷涂距离、角度和表面交点。采样序号与原轨迹点号分别显示，不能将经过重排的样本序号当作原点号。
5. 右侧小视图使用真实场景快照，包含机器人、工具和工件；切换点恢复该点记录的关节姿态。青色线为 TCP 到真实表面交点的喷距，绿色线为表面法向，红色弧为入射角，红色十字标出 TCP。相机自动聚焦 TCP/交点附近，鼠标左键拖动旋转，滚轮缩放，“重置视角”重新聚焦当前点。小视图与主场景的机器人状态、相机独立，不执行碰撞查询。

喷距是沿所选射线方向到测量工件首个有效三角面交点的距离。内部位置单位为米，界面坐标和喷距显示为毫米。角度保留已有约定：0° 为法向入射，绝对值接近 90° 为掠射；两侧 STL 法向朝向喷嘴，正负由 `(normal cross ray) dot TCP_local_X` 确定。

未命中的点仍保留原点号和 TCP 位置，曲线在该点断开；选中后显示具体原因，不绘制虚构的距离或角度。没有 TCP 位姿的点明确标记不可用。

切换方向会停止当前回放并清空旧采样；重新播放即可取得新方向结果。已打开的图表保留完整、不可变的历史采样快照，标题标明工件、机器人、轨迹和方向。选点只检查记录，不驱动机器人或修改工程。

TXT 导出增加 `# spray_direction_tcp=Z+` 或 `Z-` 元数据，原有逐点数据列和有符号角度约定保持兼容。


## 离散与连续测量分页（播放采集）

启用喷距/角度测量并播放关节轨迹，完成或停止后打开绘图窗口：

- “离散轨迹点”：保留原始轨迹点逐点实测结果，横轴为轨迹点号。
- “连续轨迹采样”：每次播放实际应用中间关节姿态后，重新计算 TCP 射线与工件首个交点，记录距离及角度；横轴为实际采样的单调时间。不是对离散喷距或角度作插值。

两页均可点击曲线、左右键或采样序号选点。右侧共用独立真实场景，显示该样本机器人姿态、工件、喷距线、法向和角弧，支持旋转、缩放及聚焦。连续页额外标明轨迹区间、区间比例、原轨迹时间和实际采样时间；切换页保留各页独立选择。

无交点样本保留并断开曲线。连续指逐帧实时采样所得的曲线，仍然是有限采样，不保证检测任意两个采样之间的极小几何变化。播放会等待帧呈现，复杂场景可能降低实际采样频率；横轴保留真实时间间隔。目标网格首次测量建立局部空间索引，后续随目标刚体变换复用，避免每帧扫描全部三角面。原 TXT 导出仍为离散轨迹点格式。


## 独立计算控制点与连续轨迹

Basic Planning 新增“计算喷涂距离和角度…”按钮。导入 TCP 位姿轨迹后即可使用，不要求先逆解或播放；原复选项改名为“播放时测量喷涂距离和角度”，只控制播放采集，关闭它仍可独立计算、查看和导出结果。

点击按钮选择测量工件、TCP Z+/Z-，并选择是否同时计算连续轨迹。默认连续采样最大间隔 0.020 s，可调整为 0.001～10 s；各轨迹段均匀细分且包含原端点。离散页优先测量原始 Cartesian 控制点；仅有关节轨迹时用其控制点 TCP 正解。

连续页对每个中间位姿重新进行工件三角网格射线求交。仅有 Cartesian 控制点时使用领域位置线性/姿态四元数球面插值（Step 轨迹按 Step）；已解关节轨迹按播放运动语义，关节线性用原关节插值正解、六轴默认 MoveL 或明确 MoveL 用端点 TCP 的直线/球面插值、XYZR 模式复用其领域插值。不是插值离散距离或角度。连续表示有限时间采样，不能保证相邻采样间所有几何细节均被发现；可减小间隔提高分辨率，最多200000个采样。

完成后自动打开双分页窗口；选中连续采样点可查看源轨迹时间、轨迹段、区间比例、TCP/交点位置及距离角度。仅有TCP位姿的分析不推测机器人关节姿态：小窗口隐藏没有关节解的机器人本体，保留喷枪、真实工件、轨迹和测量几何；喷枪根据每个样本记录的完整 TCP 位姿及原安装标定定位，包含绕 TCP Z 的滚转；具有完整已记录关节姿态的图表继续显示机器人。小窗口支持旋转、缩放、聚焦，不改变主场景。

测量不创建碰撞检测器，不修改项目轨迹、机器人关节、TCP或工件；失败/取消时保留上次完整结果。无交点保留原点号并断线。独立计算结果也可生成喷涂表面点，TXT仍导出离散测量并增加 `measurement_source=direct_trajectory_calculation`、`calculation_complete`，不冒称完成播放。切换轨迹或编辑项目后旧结果按原有失效机制清空。
